# Astrid Letterhead Generator

Branded A4 letter generator for Astrid Technology Limited (brand, address and contacts taken from astridtechnology.site).

## Use
1. Open `index.html` in any browser (no install, no server needed).
2. Fill in the reference, date, recipient and subject, then paste your message.
   - A blank line starts a new paragraph; lines starting with `-` or `•` become bullets.
   - Long letters flow onto extra pages, numbered automatically.
3. Click **Download PDF**.

Upload the official logo once under **Logo**; it is remembered in that browser.
When opened directly, the page also tries to load the logo from astridtechnology.site.

## Files
- `index.html` – standalone page (open this).
- `letterhead.body.html` – same page without the document wrapper, used for the hosted Artifact.

Company details live in the `CO` object near the top of the script.
